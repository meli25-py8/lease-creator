СОЗДАНИЕ ДОГОВОРА — ПАКЕТ ДЛЯ MAC

Это исходники и автоматический сборщик. Готового .app в архиве нет:
его нужно создать на самом Mac. Сборка на Mac пока не проверена.

1. Распакуйте всю папку в «Документы».
2. Установите Python 3.14 с https://www.python.org/downloads/macos/
   Для скачивания компонентов при первой сборке нужен интернет.
3. Дважды щёлкните build_mac.command. Он установит библиотеки в папку
   проекта и соберёт приложение. Дождитесь строки Application created.
   Если файл не запускается, откройте Терминал, введите bash и пробел,
   перетащите build_mac.command в окно Терминала и нажмите Enter.
4. В открывшейся папке dist появится LeaseCreator.app.
   Перенесите его в «Программы» и запускайте двойным щелчком.

РАСПОЗНАВАНИЕ ФОТОГРАФИЙ
Для OCR на Mac нужен Tesseract с eng, rus и kaz. Если Homebrew уже
установлен, выполните в Терминале:
    brew install tesseract tesseract-lang
Без него можно заполнить поля вручную и сохранить договор в DOCX/PDF.
Windows-движок OCR в этот пакет не включён: на Mac он не работает.

КАК ПОЛЬЗОВАТЬСЯ
Загрузите обе стороны удостоверения или введите данные вручную.
Проверьте распознанные данные, затем заполните условия аренды.
На последнем шаге проверьте текст, при необходимости отредактируйте
и сохраните договор кнопкой DOCX или PDF.
Данные текущего заполнения хранятся только до закрытия приложения.

Сборщик создаёт приложение для архитектуры Python на этом Mac.
Пакет не подписан сертификатом разработчика Apple и не нотарифицирован.
Если macOS блокирует локально собранное приложение, используйте
«Системные настройки → Конфиденциальность и безопасность → Всё равно открыть».
Отключать защиту macOS целиком не требуется.
